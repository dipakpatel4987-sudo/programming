Practical Example 6: Create a Django project and an app called doctor

# create_app.py
import subprocess
import sys

subprocess.run([sys.executable, '-m', 'django', 'startproject', 'doctorfinder'], check=True)
subprocess.run([sys.executable, 'manage.py', 'startapp', 'doctor'],
               cwd='doctorfinder', check=True)

# register the app in settings.py
path = 'doctorfinder/doctorfinder/settings.py'
text = open(path).read()
text = text.replace("'django.contrib.staticfiles',",
                    "'django.contrib.staticfiles',\n    'doctor',", 1)
open(path, 'w').write(text)
print('App doctor created and registered.')

The app folder contains models.py, views.py, admin.py, apps.py, tests.py, and migrations/. You must create urls.py and a templates/doctor/ folder yourself.
