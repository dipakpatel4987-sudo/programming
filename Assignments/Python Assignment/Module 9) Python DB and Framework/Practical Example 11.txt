Practical Example 11: Connect Django to SQLite or MySQL and manage doctor records

SQLite (default) in settings.py:
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}

MySQL: first create the database in MySQL, then install a driver.

CREATE DATABASE doctor_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

pip install pymysql          # or: pip install mysqlclient

# doctorfinder/__init__.py  (only when using PyMySQL)
import pymysql
pymysql.install_as_MySQLdb()

# settings.py  (replace DATABASES)
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'doctor_db',
        'USER': 'root',
        'PASSWORD': 'your_password',
        'HOST': 'localhost',
        'PORT': '3306',
    }
}

Create the tables and manage records:

python manage.py makemigrations
python manage.py migrate
python manage.py sqlmigrate doctor 0001      # shows the SQL Django will run
python manage.py createsuperuser
python manage.py shell

>>> from doctor.models import Doctor
>>> Doctor.objects.create(name='Ravi Mehta', specialty='Neurology', city='Surat',
...                       phone='9811122233', email='ravi@mail.com', fee=800)
>>> Doctor.objects.all()
>>> Doctor.objects.filter(city='Surat')
>>> d = Doctor.objects.get(email='ravi@mail.com')
>>> d.fee = 900
>>> d.save()
>>> d.delete()

Records can also be managed in the admin panel (/admin/) and through the CRUD pages in Practical Example 12.
